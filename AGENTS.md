Before implementing any task, create a numbered Markdown file in `@.ai-context/plan`. The file must include:

- A step-by-step implementation plan.
- A checklist for each implementation step.
- A progress indicator showing which steps are completed, in progress, and not yet started.

Keep this file updated as implementation progresses so it always reflects the current state of the task.
